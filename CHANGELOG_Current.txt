Just InCard – aktueller gemeinsamer Stand

Android 13.0.1
- Basis auf die bereitgestellte native Android-Version 13.0.0 umgestellt.
- Aufbau, Navigation sowie Livebild-/CameraX-/ML-Kit-Dateien unverändert erhalten.
- Moderne Google-Autorisierung und getrennte UI-Aktionen für Verbinden, Cloud speichern, Cloud laden und beidseitiges Synchronisieren ergänzt.
- Google Drive und Google Sheets verwenden nun getrennte, korrekte REST-Endpunkte.
- Windows-kompatible sichtbare Tabellenreiter und verlustfreies Drive-AppData-Backup eingebaut.
- Vorhandene Tabelle kann über Trefferliste, URL oder ID verbunden werden.
- Fehler beim Hinzufügen von Sammlungskarten zu Decks behoben: Das Eltern-Deck wird nicht mehr per SQLite REPLACE neu angelegt und löscht deshalb die soeben hinzugefügte Deckkarte nicht mehr.
- Deck-Hinzufügen läuft transaktional und bestätigt die tatsächlich gespeicherte Karte in der UI.
- Version auf 13.0.1 / VersionCode 13001 gesetzt.
- Stabile CI-Testsignatur für die getrennte .ci-Paket-ID ergänzt.

Windows 1.2.7
- Quellbaum und Funktionen unverändert beibehalten.

GitHub
- Gemeinsamer Workflow auf Android API 36, Gradle 9.5.0 und die Android-13.0.1-Buildtypen angepasst.
- Android und Windows werden weiterhin nach gemeinsamer Validierung parallel erstellt.
- Android liefert Debug-APK, CI-Release-APK/AAB und optional produktiv signierte APK/AAB; Windows liefert Portable-ZIP und Installer.
