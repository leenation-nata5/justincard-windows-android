Just InCard – gemeinsames GitHub-Projekt

android/  = natives Android-Projekt (Kotlin/Jetpack Compose, CameraX-Livebild, ML Kit, Google Cloud)
windows/  = Windows Desktop-Projekt, UI/Funktionsstand der aktuellen Windows-App beibehalten
shared/   = gemeinsamer Cloud-/Datenvertrag für Windows <-> Android
tools/    = plattformübergreifende Repository-Prüfungen
.github/workflows/build-all.yml = paralleler GitHub-Actions-Build für Android + Windows

GitHub erzeugt getrennte Artefakte und Logs für beide Plattformen.
Die Google-Sheets-Vorlage liegt auf beiden Plattformen identisch bei.
